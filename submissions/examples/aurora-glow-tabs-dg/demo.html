Aurora Glow Tabs

A pure CSS, accessible, hardware-accelerated segmented tab control.

Overview

Aurora Glow is a soft, animated gradient effect inspired by the northern lights. The active tab is highlighted by a blurred, moving glow that slides beneath the selected label using pure CSS transforms — no JavaScript required.

Features

  • Pure HTML & vanilla CSS — zero JS dependency
  • Hardware-accelerated with transform and opacity only
  • Dark mode compatible via prefers-color-scheme
  • Keyboard accessible & screen-reader friendly
  • Respects prefers-reduced-motion

Pricing

Free and open source under the EaseMotion CSS framework license. Drop the class names into any project and customize the aurora colors with a handful of CSS custom properties.

Tip: try tabbing through with your keyboard, or toggle your OS dark mode.
